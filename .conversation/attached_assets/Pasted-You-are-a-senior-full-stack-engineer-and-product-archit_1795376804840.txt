You are a senior full-stack engineer and product architect. Build a production-grade, web-based affiliate portal for Uptown Gas Hub, a Kenyan LPG refill business. Deliver clean, secure, well-documented, scalable code with a professional UI. This must be a first-class project — not a prototype.

Core Features (all required):

Secure registration & login — individual affiliate accounts, email/password with hashed passwords, session/JWT auth, password reset, role-based access (affiliate vs admin).

Unique referral codes — auto-generated, permanently assigned to each affiliate, non-reusable, displayed with a downloadable/printable QR code encoding the affiliate's referral link/code.

Manual refill capture (admin) — admin enters completed refills (customer, litres/amount, date, affiliate attribution via referral code/QR scan or manual assignment). Each completed refill instantly updates the affiliate's performance, commission, and tier.

Automatic tier commissions — tiers Starter → Silver → Gold → Platinum based on configurable thresholds (refill count/revenue, monthly or lifetime — make thresholds admin-configurable). Commission % auto-calculated per tier and per refill. Full commission ledger per affiliate.

Admin control centre — approve/reject affiliates, approve/void sales, manage tiers & commission rates, approve and mark payouts as paid, view reports/analytics, export CSV.

Affiliate leaderboard — ranked by sales/refills/earnings, with time filters (weekly/monthly/all-time), visible to affiliates to drive healthy competition.

M-Pesa payouts (Kenya) — integrate Safaricom Daraja (STK Push/B2C) where credentials exist; fall back to manual payout marking (admin sends via M-Pesa app, marks "paid" in portal). Payout request flow with minimum threshold.

WhatsApp notifications — notify affiliates on registration approval, new sale credited, tier upgrade, payout processed. You (the AI) decide and implement the best approach: start with a notification queue + wa.me click-to-send links and/or integrate a provider (Meta Cloud API / Africa's Talking / Twilio) behind a config flag so it can be upgraded without code changes. Handle failure/retry gracefully.

Technical Requirements:

Stack: Laravel (PHP) + MySQL + Tailwind/Bootstrap, or an equivalent robust stack you justify. Must run on shared cPanel or a Kenyan VPS.

Security: CSRF, input validation, rate limiting, SQL-injection-safe queries, audit log for admin actions, secure credential storage (.env).

Database: well-normalized schema (users, affiliates, referrals, refills/sales, commissions, tiers, payouts, notifications, audit_logs).

UI/UX: responsive, mobile-first (affiliates will use phones), clean dashboard with earnings, tier progress bar, referral QR, leaderboard.

Config-driven: tier thresholds, commission rates, payout minimums, and WhatsApp provider all editable from admin settings — no hardcoding.

Deliverables: full codebase, DB migrations/seeders, .env.example, setup/deployment README, API/route documentation, and a phased build plan (MVP → full).
